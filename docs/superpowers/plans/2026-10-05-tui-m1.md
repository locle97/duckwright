# TUI Workspace M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `duckwright --tui` opens a terminal workspace where you type tasks, start them by hand (several at once, each in its own browser session), and watch each run live with pause / step / stop.

**Architecture:** The agent loop emits typed events to a per-run hub and awaits a pause gate before each step. `startRun` (extracted from today's `runOne`) owns one run end to end without printing; plain mode prints from its events and outcome, so its output does not change. A UI-free `RunManager` holds the typed tasks, session slots and the parallel limit. An Ink app renders a pure reducer over the manager's events and turns keys into manager calls through a pure keymap.

**Tech Stack:** TypeScript run by Node ≥ 22.18 type stripping (no build step for tests), `node:test`, Ink 8 + React 19.3 (components written with `React.createElement` as `h` in `.ts` files, no JSX), `ink-testing-library` 4.

**Spec:** `docs/superpowers/specs/2026-10-04-tui-design.md` (M1 only; every "M2" part of the spec is out of scope).

## Global Constraints

- Node `>=22.18` (`package.json` `engines` unchanged). Runtime deps: exactly `ink` `^8.0.0` and `react` `^19.3.0`. Dev deps added: `ink-testing-library` `^4.0.0`, `@types/react` `^19.3.0`.
- Only `src/tui/` imports `ink` or `react`. `src/events.ts`, `src/control.ts`, `src/runs/`, `src/report/` contain no UI code.
- No JSX and no `.tsx`: components use `import { createElement as h } from "react"`.
- `cli.ts` loads the TUI only through `deps.loadTui()` (a dynamic `import("./tui/index.ts")`), so plain runs never load React.
- Without `--tui`: stdout, stderr, exit codes and `history.json` stay byte-for-byte as today. The only exception is an error thrown by `makeRunDir` or a non-`ExportError` export error. Today that is an uncaught crash. It now prints `error: <name>: <message>` on stderr and exits `1`.
- Messages, copied exactly: `--tui needs an interactive terminal` (exit 2), `give tasks inside the TUI, not with --tui` (exit 2), `<n> runs active (limit <n>)`, the placeholder `Describe a task to add…`, the quit question `stop <n> runs and quit?`.
- Defaults: `--max-parallel` `3`; session slots `<session>-1` … `<session>-N`; completion and toasts last 4 s; the add box grows to 6 lines at most.
- Every piece of page- or task-derived text is passed through `sanitize()` (Task 7) before it is rendered.
- Tests run with `npm test` (typecheck + `node --test "test/**/*.test.ts"`). New tests live in `test/runs/` and `test/tui/` and import helpers from `../helpers.ts`.

## Review Focus

1. **Control characters in task or page text.** A typed task, goal or result containing `\x1b[2J`, `\r` or a BEL must render as inert text and never clear or move the screen. This is pinned in Task 7 (`sanitize`) and Task 12 (`app_sanitizes_task_text`).
2. **Tiny or resized terminals.** At 59 columns the layout must switch to one pane, and at 39×7 it must show only `terminal too small`. It must never throw. Pinned in Task 12 (`app_narrow_layouts`).
3. **Keys aimed at a task with no live run.** `p`, `r`, `n` and `s` on an idle or finished task, and any key on an empty list, must do nothing and must not throw. Pinned in Task 11 (`keys_noop_without_live_run`).
4. **Removing the selected or last task.** The selection must stay inside the list, and remove must stay refused while a run is active. Pinned in Task 10 (`state_selection_clamps_after_remove`) and Task 5 (`manager_remove_refused_while_active`).
5. **A run ending while the quit confirmation is open.** Confirming must still stop whatever is still running, and the summary must count every run. Pinned in Task 5 (`manager_stopall_after_some_ended`).

  ```ts
  export type Phase = "observing" | "thinking" | "acting";
  export type ControlState = "running" | "paused" | "stepping" | "stopping";
  export type ExportOutcome =
    | { kind: "off" } | { kind: "skipped" }            // skipped: export on, run did not succeed
    | { kind: "written"; path: string } | { kind: "failed"; message: string };
  export interface RunOutcome {
    status: "pass" | "fail" | "stop"; exitCode: 0 | 1 | 130; success: boolean; answer: string;
    steps: number; costUsd: number; historyPath: string | null; export: ExportOutcome;
    warnings: string[]; error: string | null;          // error: the fail() message, e.g. "interrupted"
  }
  export type RunEvent =
    | { type: "run:start"; at: number; task: string; maxSteps: number; model: string; snapshot: SnapshotMode; headed: boolean; session: string; workdir: string }
    | { type: "step:start"; at: number; step: number }
    | { type: "phase"; at: number; step: number; phase: Phase }
    | { type: "decision"; at: number; step: number; decision: Decision; cost: number }
    | { type: "action:start"; at: number; step: number; index: number }
    | { type: "action:result"; at: number; step: number; index: number; result: string; code: string | null }
    | { type: "brain:error"; at: number; step: number; message: string; cost: number; failures: number }

    | { type: "control"; at: number; state: ControlState }
    | { type: "run:end"; at: number; outcome: RunOutcome };
  export type RunEventInput = RunEvent extends infer E ? (E extends RunEvent ? Omit<E, "at"> : never) : never;
  export class RunEvents {
    constructor(now?: () => number);              // default Date.now
    now(): number;
    emit(e: RunEventInput): void;                 // adds `at: this.now()`, calls listeners in order
    subscribe(fn: (e: RunEvent) => void): () => void;
  }
  ```

### Task 2: RunControl

**Files:**
- Create: `src/control.ts`
- Test: `test/control.test.ts`

**Interfaces:**
- Consumes: `RunEvents`, `ControlState` (Task 1), `AbortedError` (`src/proc.ts`).
- Produces:
  ```ts
  export class RunControl {
    constructor(controller: AbortController, events?: RunEvents);
    get state(): ControlState;
    pause(): void; resume(): void; step(): void; stop(): void;
    gate(signal: AbortSignal): Promise<void>;
  }
  ```
  Transitions (anything else is a no-op, with no event): `running` + `pause` → `paused`; `paused` + `resume` → `running`; `paused` + `step` → `stepping`; `stepping` + `pause` → `paused`; any state except `stopping` + `stop` → `stopping`, which also calls `controller.abort()`. Every real change emits `{ type: "control", state }`.
  `gate`: if `signal.aborted`, reject with `AbortedError`. If `running`, resolve. If `stepping`, set `paused` (emitting the event) and resolve. If `paused`, wait until the state changes and apply these rules again. An abort while waiting rejects with `AbortedError`. Remove the abort listener when the wait ends.

- Test: `test/runs/manager.test.ts`

**Interfaces:**
- Consumes: `RunSpec`, `RunHandle` (Task 4); `parseRunArgs`, `RunArgs`; `fixed4`.
- Produces:
  ```ts
  export type TaskId = number;
  export type TaskState = "idle" | "running" | "paused" | "passed" | "failed" | "stopping" | "stopped";
  export interface Overrides { model?: string; maxSteps?: number; headed?: boolean; export?: boolean; snapshot?: SnapshotMode }
  export interface Effective { model: string; maxSteps: number; headed: boolean; export: boolean; snapshot: SnapshotMode }
  export interface TaskSnapshot { id: TaskId; text: string; name: string; state: TaskState; overrides: Overrides; effective: Effective; error: string | null; runId: string | null; runCount: number }
  export type ManagerEvent =
    | { type: "run"; taskId: TaskId; runId: string; event: RunEvent }
    | { type: "task:added"; task: TaskSnapshot } | { type: "task:updated"; task: TaskSnapshot }
    | { type: "task:removed"; taskId: TaskId } | { type: "toast"; level: "info" | "error"; message: string };
  export type StartResult = { ok: true; runId: string } | { ok: false; reason: string };
  export interface ManagerLike {
    list(): TaskSnapshot[]; subscribe(fn: (e: ManagerEvent) => void): () => void;
    addTyped(text: string): TaskId; setOverrides(id: TaskId, o: Overrides): void; remove(id: TaskId): boolean;
    start(id: TaskId): StartResult; pause(id: TaskId): void; resume(id: TaskId): void; step(id: TaskId): void; stop(id: TaskId): void;
    activeCount(): number; stopAll(): Promise<void>;
  }
  export interface ManagerOptions { argv: string[]; defaultSkill: string; maxParallel: number; startRun(spec: RunSpec): RunHandle; preflight(args: RunArgs): string | null }
  export class RunManager implements ManagerLike {
    constructor(o: ManagerOptions);
    effectiveArgs(id: TaskId): RunArgs;     // parseRunArgs(argv, defaultSkill, {}) + overrides; session not yet set
    summary(): { lines: string[]; exitCode: number };
  }
  export function taskName(text: string, max?: number): string; // `"<first line>"`, cut with … at max (default 40) code points
  ```
- Rules:
  - **Ids:** task ids count up from 1.
  - **Snapshots:** `name` is `taskName(text)`. `runId` and `runCount` describe the latest run.
  - **`start`:** refuse when the task has an active run (`already running`) or `activeCount() >= maxParallel` (`` `${n} runs active (limit ${n})` ``). Then call `preflight(effectiveArgs)`. If that fails, store the message in `error`, emit `task:updated` and a `toast` with level error, and refuse with that message. Otherwise clear `error`, take the lowest free slot, call `startRun({ task: text, taskFile: null, args: { ...effective, session: `${args.session}-${slot}` } })`, and forward every run event as `{ type: "run", … }`.
  - **`task:updated` is emitted** on `control` events, on `run:end`, and on start, override or error changes.
  - **Slot release:** the slot is freed when `done` settles. When the outcome's `error` starts with `playwright error:`, also toast `` `${error} (if a browser is left open: playwright-cli -s=${session} close)` ``.
  - **`remove`** returns `false` and does nothing while the task has an active run.
  - **Controls:** `pause`, `resume`, `step` and `stop` act only on an active latest run, and are otherwise no-ops.
  - **`stopAll`** marks every active run as stopped by quitting, calls `stop()` on each, and awaits every `done`.
  - **`summary`:**
    - With no runs at all: `{ lines: [], exitCode: 0 }`.
    - Otherwise the first line is `` `Batch: ${p} passed, ${f} failed, ${s} stopped  Cost: $${fixed4(total)}` `` (latest runs counted; `total` is every run's cost).
    - Then one row per task that ran, in list order: `` `${pass|fail|stop}  ${name.padEnd(w)}  $${fixed4(latestCost)}  ${historyPath ?? "-"}` ``, where `w` is the longest name among those rows.
    - `exitCode`: `130` if any run was stopped by quitting; else `0` if every latest status is `pass`; else `1`.

  ```ts
    | { type: "tick"; now: number } | { type: "manager"; event: ManagerEvent }
    | { type: "select"; delta: number } | { type: "selectEdge"; edge: "first" | "last" }
    | { type: "focus"; target: "list" | "detail" | "compose" } | { type: "toggleFocus" } | { type: "escape" }
    | { type: "compose"; next: ComposeState } | { type: "form"; next: FormState | null }
    | { type: "help"; open: boolean } | { type: "confirm"; value: ViewState["confirm"] }
    | { type: "timeline"; op: "move" | "page" | "first" | "last" | "toggle" | "expandAll" | "collapseAll"; delta?: number }

  export function reduce(s: ViewState, a: UiAction): ViewState;

  export function selectedRun(s: ViewState): RunView | null;
  export function headerCounts(s: ViewState): { counts: Partial<Record<TaskState, number>>; cost: number; elapsedMs: number };
  ```
- Rules:
  - **Task list:** `task:added` appends the task. `task:updated` replaces it. `task:removed` deletes it and clamps `selected` to `[0, len-1]` (0 when empty).
  - **Run events:**
    - `run:start` creates the `RunView` (follow on, nothing expanded).
    - `step:start` appends a running step.
    - `phase` sets the step's phase.
    - `decision` fills goal, evaluation and actions, sets `memory` only when it differs from the previous step's, and adds the cost.
    - `action:start` and `action:result` set `runningAction` and the result.
    - `brain:error` sets status `brain` and `error`, adds the cost, and sets `brainFailures`. A later successful `decision` resets it to 0.
    - `step:end` sets duration and status: `done` if any action is `done` with result `done`; else `warn` if any result starts with `error:`; else `ok`.
    - `control` sets `control` and the paused timing.
    - `run:end` sets `outcome`.
  - **Follow:** while `follow` is on, `selected` tracks the last step and the running step is expanded. A `timeline` move up turns follow off, and `last` turns it back on.
  - **Header totals:** the header cost is the sum of every `RunView.cost`.
  - **Toasts:** a `toast` (from the manager or the UI) gets `until = now + 4000`. `tick` drops expired toasts.
  - **`escape`:** from `compose` it returns to the previous focus and keeps the text. From `help`, `form` or `confirm` it returns to the previous mode.
  - **Ctrl-C counter:** `ctrlC` counts presses and resets on any other action except `tick`.
